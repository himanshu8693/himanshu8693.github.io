# Himanshu Sharma — portfolio

Personal portfolio website for enterprise cloud, platform engineering, solutions engineering, DevOps, SRE, and Forward Deployed Engineer opportunities.

- **Website:** https://himanshu8693.github.io/
- **Source:** [index.html](index.html)
- **Deployment:** GitHub Pages through [Deploy portfolio](.github/workflows/deploy-pages.yml)

The page summarizes experience, selected projects, skills, education, and certifications. It retains official job titles and distinguishes portfolio simulations from validated production work. Contact details are intentionally listed on the public site by request. The original resume PDF is not hosted here.

## Publish setup

In repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**. The workflow deploys the root static site on pushes to `main`.
